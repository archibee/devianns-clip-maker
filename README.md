# ssg-clip-maker

GitHub Pages 같은 정적 호스팅에서 실행하는 로컬 영상 클립 편집기입니다. 사용자 브라우저에서 컷 편집·미리보기·자막 합성·영상 내보내기를 처리하는 것을 목표로 합니다.

> 현재는 **설계 단계**입니다. 실행 코드, 설치 스크립트, 배포 사이트는 아직 없습니다. 아래 기능은 구현 계획이며 동작 검증을 마친 기능 목록이 아닙니다.

## 목표

- 로컬 영상의 앞뒤를 자르고, 클립을 분할·삭제·재배열합니다.
- 영상과 원본 소리를 함께 미리 보고 프레임 단위로 탐색합니다.
- 한글 자막의 내용·시간·스타일을 편집하고 영상에 입혀 출력합니다.
- 가로·세로·정사각 화면과 클립별 음소거·볼륨을 지원합니다.
- 프로젝트를 저장·복원하고 실행 취소·다시 실행을 제공합니다.
- 원본 영상과 자막을 서버로 전송하지 않는 기본 구조를 유지합니다.

## 작동 방식

```text
정적 호스트 → 앱 파일 전달
                  ↓
로컬 영상 → 브라우저 편집기 → 편집한 영상 다운로드
```

WebCodecs가 영상·오디오의 디코딩과 인코딩을 맡고, Mediabunny가 컨테이너 입출력을 담당합니다. Canvas로 영상과 자막을 합성하고 Web Audio로 미리보기 소리를 재생합니다. 편집 데이터는 원본 파일과 분리해 보관합니다.

백엔드 인코딩 서버는 필요하지 않습니다. 다만 처리 속도와 코덱 지원은 사용자 기기·운영체제·브라우저에 따라 달라집니다. MP4/H.264/AAC를 우선 목표로 하며 실제 지원을 확인한 뒤 출력 옵션을 제공합니다. 지원되는 환경에서는 WebM 대안을 제공합니다.

## 초기 범위

| 항목 | 설계 목표 |
| --- | --- |
| 우선 환경 | 데스크톱 Chrome·Edge, HTTPS 또는 localhost |
| 편집 구성 | 영상 트랙 1개, 여러 클립, 수동 자막 |
| 출력 | SDR, 최대 1920×1080 / 1080×1920, 30fps, 5분 이하 |
| 기본 기술 | TypeScript strict, Vite, React, Mediabunny, WebCodecs |
| 저장 | 프로젝트 JSON·IndexedDB, 출력 크기/환경에 따라 디스크·OPFS·Blob |
| 배포 | GitHub Pages에 정적 빌드 결과 배포 |

위 수치는 개발 범위를 정한 것이며 아직 검증된 지원 보장이 아닙니다. BGM·자동 자막·다중 영상 레이어·전환 효과·배속·4K·모바일 전체 지원은 후속 범위입니다. 프로젝트 파일에는 원본 영상이 포함되지 않으므로 복원할 때 원본을 다시 선택해야 할 수 있습니다.

## 지원·라이선스 원칙

실제 브라우저 검증 결과가 쌓이기 전에는 호환성이나 성능을 보장하지 않습니다. 브라우저 내 처리라는 이유로 코덱 특허·라이브러리·폰트 라이선스 조건이 없어지는 것은 아닙니다. 의존성과 폰트를 도입할 때 고지 및 이용 조건을 확인합니다. 프로젝트 자체의 배포 라이선스는 아직 선정하지 않았습니다.
