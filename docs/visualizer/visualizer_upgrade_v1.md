## 베타 구조와 범위

기존 공통 시간 블록인 Cue에 선택적 `visualizer` 데이터만 추가한다. 새 이펙트는 자막과 구분해서 표시·선택하며 기존 드래그·라인·저장·실행 취소 경로를 재사용한다. 선택 라인의 잘린 원본 구간·복합 클립·음소거·빈 구간을 반영한다. 생성 후 소스 영상을 다시 편집해도 자동 재분석하지 않는 **생성 시점의 이펙트**이며, 필요하면 삭제 후 새로 생성한다.

32개 주파수 밴드(스테레오 채널별 강도의 최댓값)를 50ms 간격으로 요약하고 프레임 사이를 보간한다. 긴 구간은 최대 120,000개 수치 예산에 맞춰 시간 해상도를 낮춘다. 프로젝트 전체 JSON의 기존 2MB 한도·32라인 한도는 유지하며, 한도 초과 시 적용하지 않는다. 파형을 그대로 복제한 오실로스코프나 완전한 이펙트 엔진이 아닌 막대형 주파수 스펙트럼 베타다. 경과 시간은 이펙트의 원래 분석 시작점을 기준으로 한다.

## 최소 확인

단위 검사 93개·타입 검사·빌드 통과. Edge 157 헤드리스에서 2초 합성 영상으로 취소 후 데이터 보존, 실제 오디오 디코딩·분석, 투명 미리보기, 새 라인 추가, 효과 속성 열기, 배경 보존 및 AAC 소리가 포함된 MP4 출력을 확인했다. 모바일 실기기·장시간 작업 검증은 수행하지 않았다. 재현: 개발 서버 5193 포트에서 `node scripts/visualizer-browser-test.mjs`.
