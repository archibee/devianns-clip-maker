# Auto Caption V1

현재 선택한 라인의 음성 구간에 빈 자막을 생성하는 독립 확장 기능이다. 음성을 글자로 변환하는 STT 기능이 아니며, Auto Cut 실행 여부와 무관하게 사용할 수 있다.

- [v] 타임라인 AUTO CUT 옆에 AUTO CAPTION 버튼을 추가한다.
- [v] 현재 선택한 라인 전체를 대상으로 분석한다. 단일/다중 블록 선택 여부와 관계없이 해당 라인의 영상들을 분석한다.
- [v] 띄엄띄엄 배치된 영상과 합쳐진 영상 블록을 지원하고 원본 in/out 및 프로젝트 절대 시간을 유지한다.
- [v] 선택 라인에 원본 오디오가 있는 음소거되지 않은 영상이 있을 때 활성화한다. 누락 원본·지원 불가 환경·최대 라인 수는 실행 전에 안내한다. 음성이 실제로 감지되는지는 실행 조건으로 삼지 않는다.
- [v] 별도 모달에 강도 선택·분석 버튼·진행률·구간 결과·오류·완료·취소를 배치한다. 배경 클릭이나 Escape로 닫지 않으며 완료 또는 취소로만 종료한다.
- [v] 매우 높음·높음·중간·낮음·매우 낮음의 5단계 선형 프리셋을 제공한다. 음성 시작 임계값은 0.05/0.275/0.5/0.725/0.95이며 종료 임계값도 같은 비율로 선형 변화한다. 높을수록 약한 음성을 감지한다.
- [v] 편집 여백·타이트함 설정은 제공하지 않는다. 감지 구간을 확장하거나 시간을 당기지 않고 빈 자막을 배치한다. 음성 종료 확인 시간은 내부 고정값 100ms이며 실제 종료 시점으로 되돌려 구간을 확정한다.
- [v] 감지된 음성 구간마다 기본 스타일의 빈 자막을 생성하여 항상 새 라인 하나에 배치한다. 영상 사이 빈 공간에는 생성하지 않는다.
- [v] 감지 구간이 없으면 자막이나 빈 라인을 추가하지 않는다. 결과 없음은 정상 결과로 처리하며 완료·취소할 수 있다.
- [v] 분석과 결과 확인은 임시 상태이며 완료할 때만 전체 결과를 검증 후 한 번에 적용한다. 실패·취소·페이지 종료 시 미완료 변경사항은 적용하지 않는다.
- [v] 기존 영상·자막·라인의 위치와 내용을 보존하고 실행 취소 한 번으로 생성 결과를 복구한다. Auto Cut의 기존 자동 자막과도 별개로 새 라인에 추가한다.
- [v] 별도 `modules/auto-caption`에 UI·프리셋·생성 계획을 분리한다. 로컬 음성 추론 기반만 공유하고 Auto Cut 설정·상태·컷 적용 로직은 변경하지 않는다.
- [v] 정적 배포의 기존 로컬 모델·WASM·라이선스를 재사용한다. 서버·외부 API·원본 전송 없이 분석하며 취소·종료 시 해당 Worker를 해제한다.

완료 표시는 코드 반영 기준이다. 사용자 요청에 따라 빌드·Edge·실제 실행 검증은 생략한다. 음성 감지의 정확도나 브라우저별 코덱 지원은 새로 보장하지 않는다.
