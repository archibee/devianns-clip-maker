# 타임라인 업그레이드 v2

- [v] T201. 여러 라인에 영상이 있어도 영상 블록을 정확히 하나 선택하면 Auto Cut을 사용할 수 있다. 미선택·다중 선택·자막 선택 시 비활성화하며 선택 블록의 원본/오디오만 지원 여부를 확인한다.
- [v] T202. 분석·삭제 후보·원본/결과 미리보기는 선택 블록 범위만 사용한다. 합친 블록의 내부 원본 구간도 분석하며 모달의 시간은 선택 블록 시작을 0초로 표시한다. 분석/취소는 실제 프로젝트를 변경하지 않는다.
- [v] T203. 완료하면 선택 블록만 같은 라인의 원래 시작 시각부터 보존 구간으로 연결해 대체한다. 남은 컷끼리는 앞으로 당겨 붙이되 다른 영상/자막의 라인·절대 시간·내용·스타일은 유지한다. 뒤 블록 앞에 생기는 빈 공간은 유지한다.
- [v] T204. 자동 빈 자막 생성을 선택하면 완료 시 항상 맨 끝에 새 라인 하나를 추가하고 새 컷의 시간·길이·개수에 맞는 빈 자막만 배치한다. 기존 자막은 삭제/이동하지 않는다. 32라인 한도에서 새 라인을 만들 수 없으면 오류로 전체 적용을 거부한다.
- [v] T205. 모달에서 완료할 때만 결과와 새 라인을 원자적으로 적용하고 한 번의 undo/redo로 복구한다. 선택 대상/프로젝트 불일치·원본 누락·보존 구간 없음·분석 실패·취소에는 미완성 결과를 반영하지 않는다.
- [v] T206. 타임라인 버튼을 라인 추가·라인 삭제·블록 분할·블록 삭제·블록 합치기로 구분한다. 활성 라인을 삭제할 수 있고 블록이 있는 라인은 포함된 영상/자막 개수와 확인/취소 모달로 확인한다. 취소는 변경하지 않는다.
- [v] T207. 라인 삭제는 해당 라인의 블록만 삭제하고 이후 라인 번호를 당기며 블록의 절대 시간을 보존한다. 마지막 한 라인을 삭제하면 빈 한 라인을 유지한다. 삭제와 포함 블록은 한 번의 undo/redo로 복구한다. 확인 모달 중 편집과 단축키를 잠근다.
- [v] T208. 도움말을 선택 블록 Auto Cut·새 자막 라인·라인 삭제/블록 조작 용어에 맞춘다. 선택 블록만의 분석/적용·기존 블록 고정·새 라인·한도·라인 삭제/undo를 검사하고 타입 검사·빌드를 확인한다. 브라우저 검증 범위는 실제 실행한 내용만 기록한다.

검사: `npm test` 52개 및 `npm run build` 통과. Windows Edge 157.0.4341.57의 정적 하위 경로에서 `node scripts/timeline-upgrade-v2-test.mjs`로 실제 Silero 분석·새 자막 라인 적용·다른 블록/기존 자막 시간 보존·Auto Cut undo·라인 삭제 취소/확인/undo를 확인했다. 합성 비프음 fixture는 전체 보존 1컷으로 분석됐으며 실제 음성 인식 정확도 검사는 아니다. 컷 축소 후 빈 공간·합친 블록의 원본 매핑·32라인 한도는 로직 검사로 확인했다. 기존 `node scripts/timeline-upgrade-test.mjs`의 소리 포함 MP4 출력 검사도 통과했다. 두 브라우저 검사는 기존 합성 fixture `test-results/red.mp4`, `blue.mp4`가 필요하다.
