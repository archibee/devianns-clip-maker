# 타임라인 업그레이드 v6

- [v] T601. 영상 블록의 HTML 드래그 고스트 방식이 자막의 포인터 드래그와 다른 문제를 개선한다. 영상도 포인터를 누른 위치를 유지한 채 블록 자체의 위치 초안이 마우스를 따라가고, 마우스를 놓을 때만 시간/라인 이동을 확정한다. 에셋 임포트 드래그는 유지한다.
- [v] T602. 같은 라인과 다른 라인 이동, 가까운 시작/끝 경계 스냅, 시작 0초 제한, 같은 라인의 영상/자막 충돌 표시·거부를 지원한다. 취소/Escape/포인터 취소는 원래 위치로 돌아가고, 유효한 이동 한 번은 한 번의 undo로 복구한다. 오디오·음소거·원본 구간·변환은 유지한다.
- [v] T603. 일반 클릭/키보드 선택, Ctrl/⌘ 혼합 다중 선택, 음소거·트림 핸들 동작을 유지한다. 선택용 클릭은 이동 명령을 만들지 않고, 드래그를 시작할 때 원본 시작 시각으로 강제 시킹하지 않는다. 드래그 종료 뒤 클릭이 빈 공간 선택 해제로 오인되지 않게 한다.
- [v] T604. 진행바가 보이는 타임라인 오른쪽 경계를 넘으면 다음 화면 구간으로 가로 스크롤한다. 이후 경계에서도 계속 넘기며 큰 시간 점프도 처리한다. 왼쪽 밖으로 탐색하면 해당 구간을 보여주고 현재 실제 viewport 너비/확대 배율/콘텐츠 너비를 사용한다.
- [v] T605. 자동 따라가기는 시간 변경과 타임라인 폭/확대 변경에 반응한다. 일시 정지 중 사용자의 수동 스크롤을 즉시 되돌리지 않고 드래그/트림을 방해하지 않는다. 세로 스크롤·고정 눈금·눈금 클릭 좌표·진행바와 블록의 시간 정렬은 유지한다.
- [v] T606. 포인터 영상 블록 UI와 순수 배치/스크롤 계산을 분리하고 기존 위치 변경 명령을 직접 사용한다. 배치/충돌·페이지 경계/반복 이동을 짧은 검사로 확인하고 타입 검사·빌드 및 브라우저 드래그/스크롤을 확인한다. 실제 검사 범위만 기록하고 완료 체크한다.

확인: `npm test` 61개, `npm run build`(타입 검사·고정 체크리스트 검사 포함) 통과. Windows Edge 157.0.4341.57의 정적 하위 경로에서 `node scripts/timeline-upgrade-v6-test.mjs`로 영상 블록 자체의 포인터 초안·라인 이동 확정·원본/음소거 유지·undo/Escape 취소를 확인했다. 재생 위치 탐색으로 오른쪽 화면 경계 3회 연속 따라가기, viewport 폭 변경, 일시 정지 중 수동 스크롤 유지를 확인했다. 기존 v3 브라우저 검사의 혼합 선택·음소거·실제 MP4 출력도 통과했다. 브라우저 검사는 기존 합성 fixture `test-results/red.mp4`가 필요하다. 장시간 연속 재생과 다른 브라우저는 이번에 확인하지 않았다.
