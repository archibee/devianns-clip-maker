# 타임라인 업그레이드 v8

- [v] T801. 활성 라인에서 영상만 선택된 상태의 Ctrl/⌘+A는 해당 라인의 영상만, 자막만 선택된 상태에서는 해당 라인의 자막만 전체 선택한다. 다른 라인은 제외한다.
- [v] T802. 활성 라인에 선택 블록이 없으면 Ctrl/⌘+A로 그 라인의 모든 블록을 혼합 선택한다. 다른 라인에 남아 있는 선택은 활성 라인의 종류 판정에 사용하지 않는다. 혼합 선택에서 다시 Ctrl/⌘+A를 눌러도 해당 라인의 전체 선택을 유지한다. 빈 라인은 아무것도 선택하지 않는다.
- [v] T803. 종류 판정/라인 선택 계산은 공통 블록 목록과 종류 문자열 기반의 순수 함수로 분리한다. 나중에 새 블록 종류가 모델/UI에 추가되면 목록 어댑터에 연결해 같은 전체 선택 규칙을 사용할 수 있게 한다. 이번에 아직 존재하지 않는 블록 모델이나 UI는 추가하지 않는다.
- [v] T804. 입력창·모달·편집 잠금 중 기본 입력 보호를 유지하고 선택 변경만 수행한다. 기존 혼합 선택의 복사/삭제/이동·속성 편집은 유지한다. 도움말·문서 색인에 규칙을 반영하고 단위 검사·타입 검사·빌드 및 간단한 브라우저 확인 후 체크한다.

확인: `npm test` 70개 및 `npm run build` 통과. Windows Edge의 정적 하위 경로에서 영상만/자막만 선택, 빈 공간 클릭 후 라인 전체 선택, 혼합 전체 선택 반복, 다른 라인의 선택 제외를 확인했다. 새 종류 문자열의 전체/종류별 선택은 순수 함수 검사로 확인했으며 실제 새 블록 모델은 추가하지 않았다.
