# 타임라인 업그레이드 v4

- [v] T401. 타임라인 메뉴 버튼 그룹을 오른쪽에 정렬한다. 기존 그룹 구분·확대 조절·좁은 화면의 가로 스크롤은 유지한다.
- [v] T402. 네 이동 버튼의 표시 문구와 접근성 이름을 `라인 위로`, `라인 아래로`, `블록 왼쪽으로`, `블록 오른쪽으로`로 통일한다. 모든 방향 아이콘은 텍스트 왼쪽에 배치한다.
- [v] T403. 이동 로직·활성화 조건은 유지하며 기존 브라우저 검사 이름을 맞춘다. 타입 검사·빌드로 간단히 확인하고 완료 항목을 체크한다.
- [v] T404. 미리보기 도구 버튼을 `CROP`, `MOVE`, `RESIZE`, 타임라인 확장 버튼을 `AUTO CUT`으로 대문자 표시한다. 기능은 유지하고 관련 브라우저 검사의 버튼 이름을 맞춘다.
- [v] T405. T402의 이동 버튼 문구를 `라인 위`, `라인 아래`, `블록 왼쪽`, `블록 오른쪽`으로 단축한다. 표시 문구·접근성 이름·관련 검사 이름에 동일하게 반영하고 아이콘과 이동 동작은 유지한다.
- [v] T406. `CROP`, `MOVE`, `RESIZE` 버튼의 텍스트 왼쪽에 각각 크롭 모서리·네 방향 이동·대각선 크기 조절 아이콘을 표시한다. 기존 버튼 기능·선택 상태·접근성 이름은 유지하며 타입 검사로 간단히 확인한다.
- [v] T407. 도움말 모달의 긴 타임라인 설명을 라인/블록/음소거/AUTO CUT별 카드로 구분하고 빠른 시작·단축키·저장 안내의 정보 순서와 간격을 정돈한다. 현재 버튼 명칭을 사용하고 중복 설명을 줄이며 좁은 화면에서도 읽기 쉽게 배치한다. 도움말 외 편집 동작은 유지하고 타입 검사·빌드로 확인한다.
