# 타임라인 업그레이드 v7

- [v] T701. 블록 이동 중 같은 라인의 다른 블록과 겹치는 후보는 원래 위치로 되돌리지 않고, 포인터가 원하는 위치에서 가장 가까운 배치 가능한 인접 시작/끝 경계로 보정한다. 영상·자막 이동에 같은 규칙을 적용하며 원본 길이는 유지한다. 가까운 경계 스냅과 0초 제한을 유지한다.
- [v] T702. 같은 라인에서 빈틈 없이 이어진 선택 블록들을 선택된 블록 중 하나로 드래그하면 묶음 이동한다. 영상·자막 혼합도 가능하며 묶음은 해당 라인 안에서 상대 간격·길이·원본·음소거·스타일을 보존한다. 드래그 중 모두 이동 초안을 표시하고 놓을 때 한 명령으로 확정한다.
- [v] T703. 다른 라인에 걸친 선택이나 불연속 선택은 묶음 이동 조건에서 제외하고 잡은 블록만 이동한다. Ctrl/⌘ 클릭의 선택/해제와 단일 선택, 트림·음소거 버튼, 취소/Escape, 충돌 보정, undo/redo를 유지한다. 취소는 프로젝트를 변경하지 않는다.
- [v] T704. 미리보기 MOVE 드래그 중 가로·세로 0/25/50/75/100% 격자 가이드를 표시한다. Crop/Resize 후 실제 표시 사각형 중심을 기준으로 각 축을 독립적으로 가까운 선에 스냅하고 교차점에도 배치할 수 있다. 스냅된 선과 중심점을 강조하며 화면상의 약 8px 이내에서 적용한다.
- [v] T705. MOVE의 실시간 미리보기·확정 데이터와 출력 변환을 일치시키고 드래그 종료/취소 시 가이드를 숨긴다. 기존 Crop/Resize 기능과 출력 화면 비율은 유지한다. 격자/중심 표시 자체는 출력에 포함하지 않는다.
- [v] T706. Ctrl/⌘+A는 활성 라인 안에서 현재 선택한 종류만 전체 선택한다. 영상 선택 시 그 라인의 영상만, 자막 선택 시 그 라인의 자막만 선택하며 다른 라인은 포함하지 않는다. 입력창/모달/잠금 보호와 무선택 시 미실행은 유지한다.
- [v] T707. 공통 배치·묶음 이동·중심 스냅 계산을 분리하고 요구사항에 대한 순수 검사·타입 검사·빌드와 간단한 브라우저 조작을 확인한다. 도움말과 문서 색인에 새 동작을 반영하고 실제 구현 완료 항목만 체크한다.

확인: `npm test` 67개 및 `npm run build`(타입 검사·고정 체크리스트 검사 포함) 통과. Windows Edge 157.0.4341.57의 정적 하위 경로에서 `node scripts/timeline-upgrade-v7-test.mjs`로 라인/종류별 Ctrl+A, 영상·자막 연속 묶음의 동시 초안/확정/undo, 영상·자막 각각의 겹친 드롭 경계 보정, Crop/Resize된 영상의 MOVE 격자/교차점 스냅과 확정값을 확인했다. 기존 v6 드래그/스크롤 및 v3 음소거/실제 MP4 출력 검사도 통과했다. 브라우저 검사는 기존 합성 fixture `test-results/red.mp4`가 필요하며 다른 브라우저와 대량 블록 프로젝트는 이번에 검사하지 않았다.
