# 타임라인 업그레이드 v5

- [v] T501. 타임라인을 세로 스크롤해도 시간 눈금바와 재생 위치 손잡이는 타임라인 상단에 고정한다. 라인/블록은 그 아래로 스크롤되고 눈금바가 가려지지 않게 배경·표시 순서를 유지한다.
- [v] T502. 가로 스크롤에서는 눈금과 블록의 시간 좌표가 함께 이동하도록 유지한다. 눈금 클릭/드래그 탐색·확대·재생 위치 표시와 기존 라인 배치는 유지한다.
- [v] T503. 기존 눈금바의 CSS 배치와 상단 여백을 직접 수정한다. 타입 검사·빌드와 간단한 브라우저 좌표 확인 후 완료 항목을 체크한다.
- [v] T504. 영상·자막 블록은 같은 높이와 상단 여백으로 표시한다. 공통 높이 변수를 사용해 블록은 60px, 라인은 68px로 소폭 줄이고 파일명·길이·음소거 버튼·트림 핸들을 위한 공간은 유지한다. 라인 라벨·배경 높이도 일치시키며 편집 데이터와 동작은 변경하지 않는다. 타입 검사·빌드로 확인한다.
- [v] T505. 타임라인의 빈 라인/여백을 클릭하면 영상·자막 블록의 단일/다중 선택을 모두 해제한다. 블록·내부 버튼·트림 핸들·라인 라벨·눈금·메뉴 조작은 기존 선택 동작을 유지하고 편집 잠금 중에는 적용하지 않는다. 타입 검사로 간단히 확인한다.
