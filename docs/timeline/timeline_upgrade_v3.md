# 타임라인 업그레이드 v3

- [v] T301. 기존 좌우 이동 버튼을 `블록 이동 ←`, `블록 이동 →`로 명시한다. 활성 라인의 순서를 바꾸는 `라인 위 ↑`, `라인 아래 ↓`를 추가하고 첫/마지막 라인의 불가능한 방향은 비활성화한다.
- [v] T302. 라인 순서 변경은 이웃 라인과 포함 영상/자막을 함께 교환한다. 빈 라인도 이동하며 블록 시간·원본·변환·음소거·선택을 보존한다. 활성 라인은 이동한 라인을 따라가고 저장·복구·미리보기/출력 레이어와 undo/redo에 반영한다.
- [v] T303. 각 영상 블록의 연결 오디오 영역에 아이콘과 상태가 있는 음소거/음소거 해제 버튼을 추가한다. 소리가 없는 영상은 비활성화하며 자막에는 버튼을 넣지 않는다. 버튼 조작은 블록 선택·드래그·시킹으로 전파되지 않는다.
- [v] T304. Ctrl/⌘+클릭으로 영상과 자막을 혼합 다중 선택할 수 있다. 선택된 영상의 음소거 버튼을 누르면 선택 영상 중 원본 오디오가 있는 블록 전체에 같은 상태를 적용하고 자막·무음 원본은 무시한다. 클릭한 블록의 현재 상태를 반전해 일괄 음소거/해제를 결정한다. 선택 밖 영상의 버튼은 해당 블록만 바꾼다.
- [v] T305. 혼합 선택에서 블록 삭제·잘라내기·복사/붙여넣기는 선택 블록 전체를 처리한다. 속성 패널은 각 탭의 같은 종류 선택에 공통 설정을 적용한다. 전체 선택 단축키는 활성 속성 탭의 선택 종류 전체를 선택하며 Auto Cut은 영상 하나만 단독 선택 시에만 사용한다.
- [v] T306. 음소거는 원본 파일과 영상 프레임·블록 시간에 영향을 주지 않는다. 같은 스트리밍 오디오 경로를 쓰는 미리보기/출력에서 음소거 구간을 제외하고 모두 음소거면 무음 영상을 출력한다. 분할·복사·붙여넣기·합치기·Auto Cut·JSON·자동 저장에서 상태를 보존하고 일괄 변경은 한 번에 undo/redo한다. 합친 블록도 전체 음소거/해제가 가능하다.
- [v] T307. 타임라인 메뉴를 라인 조작/블록 조작/확장 기능(Auto Cut) 그룹으로 나눠 간격·구분선으로 구별하고 각 버튼에 용도별 아이콘과 텍스트·접근성 이름을 제공한다. 메뉴의 `영상 + 원본 오디오 연결` 문구는 제거한다. 좁은 화면에서도 메뉴를 스크롤해 접근할 수 있게 한다.
- [v] T308. 도움말에 라인 순서·혼합 선택·음소거 일괄 적용 규칙을 추가한다. 라인 교환/경계/undo, 음소거 대상/상태 보존/오디오 출력 로직을 검사하고 타입 검사·빌드를 확인한다. 실제 브라우저에서 검사한 범위만 기록한다.

검사: `npm test` 57개 및 `npm run build` 통과. Windows Edge 157.0.4341.57의 `/devianns-clip-maker/` 정적 경로에서 `node scripts/timeline-upgrade-v3-test.mjs`로 라인 순서/활성 라인, 영상·자막 혼합 선택, 개별/일괄 음소거·해제·undo/redo, 전체 음소거 미리보기 재생, 영상 트랙을 유지한 무음 MP4 출력, 좁은 화면 메뉴 스크롤을 확인했다. 기존 v1(소리 합산 출력)·v2(실제 Silero 분석/새 자막 라인/라인 삭제) 브라우저 검사도 통과했다. 브라우저 검사는 기존 합성 fixture `test-results/red.mp4`, `blue.mp4`가 필요하며 다른 브라우저와 대용량 프로젝트는 이번에 검사하지 않았다.
