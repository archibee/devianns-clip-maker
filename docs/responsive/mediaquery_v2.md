# 미디어쿼리 V2 · Auto Caption 오류 수정

- [v] 오디오 샘플 공백이 하나라도 있으면 Auto Caption 전체 적용을 차단하던 오류 처리를 제거한다. 영상과 오디오의 시작·종료 시간 차이 등으로 생기는 공백은 기존 PCM 리더의 무음 채움으로 처리하고, 원래 타임라인 시간을 유지하여 감지된 음성 구간만 빈 자막으로 생성한다.
- [v] 공백은 모달 안내로 표시하되 분석·완료를 차단하지 않는다. 실제 디코더 오류·원본 누락 등은 기존 오류 처리를 유지하며 Auto Cut 동작은 변경하지 않는다.

요청에 따라 브라우저·직접 실행 검증은 생략했다.
