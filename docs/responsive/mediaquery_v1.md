# 미디어쿼리 업그레이드 V1

PC 편집 화면을 유지하면서 작은 화면 전용 스타일과 터치 정책을 추가한다. 완료 표시는 코드 반영 기준이며 실제 기기에서의 사용성·코덱 지원을 검증했다는 의미가 아니다.

- [v] 1150px 초과 PC 화면은 기존 디자인과 구조를 유지한다.
- [v] 601~1150px 태블릿에서는 에셋과 미리보기를 나란히 배치하고, 타임라인과 속성을 아래에 배치한다.
- [v] 600px 이하 모바일에서는 미리보기 → 타임라인 → 속성 → 에셋을 한 열로 배치하고 페이지 스크롤로 접근한다.
- [v] 작은 화면에서 상단 버튼과 타임라인 도구를 잘리지 않게 재배치하고, 도구 목록의 가로 스크롤을 제공한다.
- [v] 터치용 버튼·에셋 추가/삭제·변형 핸들의 조작 영역을 확대하고, 입력칸·드롭다운 글자 크기와 슬라이더 높이를 확보한다.
- [v] 모달의 너비·높이·버튼 배치를 작은 화면에 맞추고 화면 안전 여백을 반영한다.
- [v] 작은 화면에 한해 viewport, touch-action, 다중 터치 및 Safari 제스처 처리를 통해 핀치·더블 탭 확대를 억제한다. 일반 스크롤과 기존 블록 드래그, 텍스트 입력은 유지한다.
- [v] 화면 크기가 PC 범위로 돌아오면 기존 viewport 설정을 복구하고 터치 차단을 해제한다.
- [v] 반응형 스타일과 터치 처리를 별도 파일로 격리하며 프로젝트 데이터·미디어 처리·내보내기 로직은 변경하지 않는다.

요청에 따라 빌드·브라우저 실행·실제 기기 검증은 생략한다. 브라우저/OS의 접근성 확대 정책은 앱 설정보다 우선할 수 있으며, 모바일 코덱·메모리 지원 범위를 새로 보장하지 않는다.
