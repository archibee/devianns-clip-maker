# UI 업그레이드 V2 — 공간 정리와 패널 크기 조절

- [v] PC·태블릿·모바일의 속성 입력, 구분선, 패널 제목, 모달의 여백을 좁고 일관된 기준으로 정리한다. 터치 입력과 재생 버튼의 조작 크기는 유지한다.
- [v] 맨 아래 자동 저장 상태줄과 초 단위 이동 입력칸을 통째로 제거한다. 자동 저장은 유지하고 실패는 기존 토스트로 알린다. 확보한 공간을 타임라인에 배정한다.
- [v] 상단 제목·프로젝트 도구줄 높이를 조금 줄인다.
- [v] PC에서 미디어·미리보기·속성 사이 너비, 위쪽 패널·타임라인 사이 높이를 경계 드래그로 조절한다.
- [v] 태블릿에서는 미디어·미리보기 너비와 위쪽·타임라인·속성 사이 높이, 모바일에서는 세로로 배치된 네 패널 사이 높이를 조절한다.
- [v] 경계는 마우스·터치 드래그와 방향키로 조절한다. Shift+방향키는 큰 단위 조절, 더블클릭 또는 Home은 기본 배치 복구, 드래그 중 Escape는 취소한다.
- [v] 미리보기·속성·타임라인이 사라지지 않도록 최소 크기를 적용한다. 화면 폭이 PC·태블릿·모바일 경계를 넘으면 해당 화면의 기본 배치로 돌아간다.
- [v] 크기 조절은 UI 상태만 바꾸며 프로젝트·실행 취소·영상 좌표를 변경하지 않는다. 미리보기 영상의 원래 종횡비와 타임라인 스크롤·편집을 유지한다.

구현은 `useWorkspaceResize.tsx`와 순수 크기 계산 `workspace-layout.ts`로 분리했다. 경계는 기존 Grid의 행·열 크기만 조절하며 미디어 처리에는 관여하지 않는다. 배치는 새로고침 시 초기화한다.

확인: Edge 헤드리스의 1440·1024·768·390·320px 화면에서 경계 드래그, 프로젝트 데이터 보존, 미리보기 비율, 자막 수정, 재생, 초기화와 반응형 전환을 확인했다. 작은 화면은 터치 에뮬레이션이며 실제 기기 검증은 아니다. 단위 검사 85개 및 타입 검사·빌드가 통과했다. 재현 명령은 개발 서버 5193 포트에서 `node scripts/ui-upgrade-v2-test.mjs`다.
