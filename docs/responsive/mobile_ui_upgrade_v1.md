# 모바일 UI 업그레이드 V1

- [v] 모바일 너비(600px 이하)에서는 메인 로고를 숨기고 프로젝트 이름 입력을 상단바 왼쪽에 배치한다. 입력 너비는 80~128px로 확보하고 나머지 공간은 메뉴가 사용한다.
- [v] PC 로고와 태블릿 상단바는 유지한다. 작은 화면 메뉴는 한 줄과 가로 스크롤을 유지한다.
- [v] 모바일·태블릿의 이전/다음·처음/끝 버튼을 최소 너비 36px·높이 44px, 재생 버튼을 44px로 확보하고 flex 축소를 막는다. 페이지 너비가 아닌 실제 미리보기 컨테이너 너비를 기준으로 공간이 충분하면 이동 버튼 너비도 44px까지 넓힌다.
- [v] 재생 컨트롤 높이를 54px로 맞추고 시간 표시·버튼을 한 줄에 배치한다. 불필요한 작은 버튼 크기를 강제하던 규칙을 직접 수정한다.
- [v] 작은 화면 미디어 패널의 장식 번호를 숨겨 녹화 버튼 공간을 확보하고 녹화 버튼의 터치 높이를 32px로 제공한다.
- [v] 새 녹화 모달의 미리보기·진행 상태·완료/취소/파일 저장 버튼이 좁은 너비에도 접근 가능하도록 스크롤과 버튼 배치를 적용한다.

## 확인 범위

Windows Edge 157의 실제 렌더링과 터치 에뮬레이션으로 320·390·600·768·1024px 너비를 확인했다. 페이지 전체 가로 넘침 없이 상단바 38px를 유지했고, 모바일 프로젝트 입력이 왼쪽에 표시되며 재생/이동 버튼의 최소 크기와 녹화 모달의 표시·취소가 통과했다. 실제 휴대기기·가상 키보드·iOS Safari 검증과 구분한다.

검증은 개발 서버를 5193 포트로 실행한 뒤 `node scripts/record-browser-test.mjs`로 재현할 수 있다. 화면·측정 결과는 `test-results/record-v1/`에 남긴다.

타입 검사를 포함한 빌드 및 단위 검사 77개가 통과했다. 실제 모바일에서 탭 녹화가 지원된다는 의미는 아니며 해당 기능의 지원 조건은 녹화 V1 문서를 따른다.
