# 진입 화면 업그레이드 V1

- [v] 최초 HTML부터 회색조 다크 배경과 중앙 로고·`Devianns Clip Maker` 제목을 표시한다. 로고와 초기 스타일은 외부 파일 로딩에 의존하지 않는다.
- [v] 편집기 준비가 끝날 때까지 로딩바를 표시한다. 다운로드 퍼센트를 알 수 없으므로 진행 중 애니메이션으로 표현하고, 준비 완료 시 진입 화면을 숨긴다.
- [v] 앱 스크립트·필수 스타일 로딩 실패, 초기 실행 오류, 처리되지 않은 초기 Promise 오류, 오프라인·장시간 로딩을 같은 화면에서 안내한다. 오류 시 로딩 애니메이션을 멈추고 다시 시도 버튼을 제공한다.
- [v] JavaScript 비활성 상태에도 중앙 안내를 제공한다. 모바일·태블릿과 모션 감소 설정을 지원한다.
- [v] 편집 시작 후의 일반 작업 오류를 진입 오류로 가로채지 않으며 프로젝트·미디어·저장소를 변경하지 않는다. 기존 정적 배포·하위 경로를 유지한다.

서버가 최초 HTML 자체를 반환하지 못하거나 호스팅 서비스의 자체 오류 페이지로 대체한 경우, 전달되지 않은 앱 코드는 실행할 수 없다. 이 범위는 브라우저·호스팅의 오류 화면이 담당한다. 앱 HTML을 받은 이후의 파일 응답 오류는 진입 화면에서 안내하며, 확인하지 못한 HTTP 상태 코드를 추측해 표시하지 않는다.

확인: 타입 검사·빌드 통과. 빌드된 정적 파일을 하위 경로에 제공해 Edge 헤드리스에서 1440·768·390px 로딩 화면과 편집기 진입을 확인했다. 스크립트 HTTP 500·스타일 404·초기 실행 오류·Promise 오류·로딩 시간 초과를 주입해 오류 안내를 확인했고, 재시도 후 진입 및 JavaScript 비활성 안내도 확인했다. 재현: `node scripts/startup-browser-test.mjs`(선행 빌드 필요). 실제 호스팅 장애 검증과는 구분한다.
