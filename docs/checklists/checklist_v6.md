## 검증 결과 및 수정

검증 환경: Windows, 실제 설치된 Edge 157의 headless 모드, 합성 MP4 영상·동기 비프음 fixture. 사용자 파일이나 원본 내용은 외부로 전송하지 않았다. 브라우저 권한은 자동화 컨텍스트에서 허용/거부했으며 운영체제 권한 창을 직접 클릭한 검사는 아니다.

### 미완료 및 유지되는 제약

- V617: `https://devianns.github.io/devianns-clip-maker/`와 기존 이름의 `https://devianns.github.io/ssg-clip-maker/` 모두 HTTP 404를 반환했다. 실제 공개 최신 배포의 동작은 확인하지 못했다. 로컬 정적 호스팅 검사는 통과했지만 이 항목을 대신 체크하지 않았다. 배포 설정 변경·커밋·푸시·공개 배포는 수행하지 않았다.
- 프로젝트 JSON에는 원본 영상과 로컬 폰트 파일이 포함되지 않는다. 다른 PC/브라우저 또는 저장 데이터 삭제 뒤에는 원본 재연결과 폰트 재선택이 필요하다. 폰트 누락 시 기본 폰트로 바꿔 편집/저장을 계속할 수 있다.
- 자막은 프로젝트의 고정 시간에 놓인다. 영상 순서를 사용자가 변경하면 자막의 의미상 동기까지 자동으로 따라가지는 않는다. 합치기는 인접한 블록을 대상으로 하며 비인접 선택에는 안내를 표시한다.
- 실제 미디어 검증은 위 Edge/Windows 환경과 합성 fixture 범위다. 모든 브라우저·임의 코덱·장시간 원본·사용자 장치의 소리 출력까지 보장하는 결과는 아니다.
- 기존 README/STRUCTURE 등은 사용자 지시에 따라 갱신하지 않았다. 과거 5분 제한 등 오래된 설명과 현행 동작의 차이는 이 문서 및 버전별 체크리스트를 기준으로 판단한다.
