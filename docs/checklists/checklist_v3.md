# Devianns Clip Maker v3

- [v] V301. 전체 너비와 요소는 유지하고 상단 바·공통 패널 제목·타임라인 블록/영역의 높이를 줄여 미리보기 공간을 확보한다.
- [v] V302. 미디어/속성 패널의 요청한 하단 안내 문구와 영역을 제거한다.
- [v] V303. 지원 브라우저의 로컬 폰트 접근 권한으로 폰트 목록을 읽고 선택한 폰트를 자막·미리보기·출력에 적용한다. 미지원 환경은 기본 폰트를 유지한다.
- [v] V304. 미리보기의 crop/move/resize를 상호 배타적으로 토글하고 선택 영상 블록에만 마우스 조작을 적용한다.
- [v] V305. Ctrl/Cmd+클릭으로 영상 블록을 다중 선택하고 분할/삭제 옆의 합치기 버튼으로 원본·소리·편집을 보존한 단일 블록으로 합친다.
- [v] V306. 선택한 영상/자막 블록의 복사·붙여넣기와 겹침 방지를 지원하고 연속 붙여넣기 시 끝으로 이동한다.
- [v] V307. 고정 5분 및 원본 영상 끝에 묶인 타임라인 제한을 제거하고 영상/자막의 가장 늦은 끝을 전체 재생 길이로 계산한다.
- [v] V308. 연장된 타임라인·영상 없는 구간·합친 영상·로컬 폰트·crop/move/resize를 미리보기/오디오/출력/프로젝트 저장에 연결한다.
- [v] V309. 타입 검사와 빌드만 간단히 확인하고 기능의 직접 사용 검증은 사용자에게 넘긴다. 다른 문서나 별도 구현/검증 메모는 작성하지 않는다.
