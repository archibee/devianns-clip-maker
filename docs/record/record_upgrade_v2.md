# 녹화 업그레이드 V2 · 전체/사각형 지정

## 요구사항과 구현

- [v] 탭 선택 후 녹화 전 ‘전체’ 또는 ‘사각형 지정’을 선택한다. 기본값은 전체이며 녹화 중에는 범위를 변경하지 않는다.
- [v] 미리보기의 실제 공유 영상 위에서 사각형을 새로 그리거나 이동·모서리 크기 조절을 할 수 있게 한다. 영상 바깥의 미리보기 여백은 선택 좌표에 포함하지 않는다.
- [v] 마우스·터치 드래그를 지원하고 X/Y/너비/높이 백분율 입력과 영역 초기화를 제공한다. 빈 영역이나 화면 밖 영역은 차단하며 최소 너비·높이는 각각 2%다.
- [v] 녹화 시작 시 첫 영상 프레임으로 출력 크기를 정하고 끝까지 고정한다. 선택 영역의 비율을 유지하며 최대 1920×1080 이내로 맞추고 원본보다 확대하지 않는다.
- [v] 공유 탭의 전체화면 전환·창 크기 변화에도 원본의 현재 비율을 유지해 고정 캔버스에 합성한다. 비율이 달라지면 검은 여백으로 채우며 가로·세로를 따로 늘리지 않는다.
- [v] 공유 소리를 출력 스트림에 그대로 연결하고 기존 파일 마무리 → 자동 영상 에셋 추가 → 파일 저장 흐름을 유지한다.
- [v] 지원 브라우저에서는 원본 영상 프레임을 버퍼 1개로 직접 받아 합성한다. 미지원 환경은 비디오 프레임 콜백 방식으로 처리하며 브라우저·백그라운드 상태에 따라 처리 속도는 달라질 수 있다. VideoFrame·프레임 리더·캔버스 출력 트랙은 완료·실패·취소에 모두 해제한다.
- [v] 영상 준비 중 중복 시작을 막고 취소 후 늦게 준비된 출력도 폐기한다. V1의 녹화 용량·시간 상한과 취소 시 미추가 원칙을 유지한다.

## 선택 영역의 의미

사각형은 공유 화면 안의 **상대 위치**다. 다른 사이트의 영상 요소를 찾아 자동 추적하는 기능은 아니다. 탭의 배치·스크롤·영상 위치가 바뀌면 선택 위치와 대상이 달라질 수 있으므로 다음 녹화 전에 다시 지정해야 한다. 고정 출력 크기·비율 유지는 이런 위치 추적과 구분한다.

## 확인

Windows Edge에서 실제 다른 탭을 공유해 전체·왼쪽 사각형 영역을 녹화하면서 대상 탭의 크기와 전체화면 상태를 변경했다. 출력 해상도가 시작 시 정한 크기로 유지되는지, 원형 테스트 도형이 찌그러지지 않는지, 선택하지 않은 오른쪽 화면이 제외되는지, 비율 변화 시 검은 여백이 생기는지, 소리가 남는지 확인했다.

320px·768px 화면에서 터치 사각형 선택과 모달 넘침을 확인했다. 기존 녹화 브라우저 검사에서는 자동 에셋 추가·타임라인 재생·소리 포함 MP4 출력도 통과했다. 실제 휴대기기·Safari·장시간 녹화는 미검증이다.

재현: 개발 서버를 5193 포트에서 실행한 뒤 `node scripts/record-v2-browser-test.mjs`. 결과·캡처는 Git 제외 경로 `test-results/record-v2/`에 남긴다.

`npm test`의 81개 검사와 `npm run build`가 통과했다. 단위 검사에는 영역·출력 비율 계산과 준비 중 취소 후 늦은 출력 해제도 포함한다. 프레임 직접 처리 API는 브라우저별 노출 위치가 다르므로 기능을 감지하며, 대체 경로의 백그라운드 성능까지 동일하게 보장하지 않는다. [프레임 처리 API 참고](https://developer.mozilla.org/en-US/docs/Web/API/MediaStreamTrackProcessor)
