# 녹화 업그레이드 V3 — 브라우저 공유 오디오

- [v] 전체 화면·창을 녹화할 때도 브라우저에 시스템 오디오 공유를 요청한다. `systemAudio: include`, `windowAudio: system`을 사용하며 로컬 소리 재생을 억제하지 않는다.
- [v] 공유 대상 종류로 음성 유무를 추측하지 않는다. 실제 반환된 오디오 트랙이 있으면 전체·사각형 녹화 모두 그대로 보존한다.
- [v] 오디오 트랙이 없으면 공유 설정을 다시 선택하도록 안내하고, 계속 시작하면 무음이라는 사실을 표시한다. 마이크를 몰래 대신 녹음하지 않는다.
- [v] 공유창에서 탭 또는 시스템 소리를 켜야 한다는 설명과 브라우저·OS 제한을 안내한다.

스피커에서 소리가 난다는 사실만으로 웹페이지가 그 소리에 접근할 수 있는 것은 아니다. 위 옵션은 브라우저의 공유 선택지를 요청하는 힌트이며 강제 권한이 아니다. 최소화된 다른 탭의 소리도 **시스템 오디오 트랙으로 실제 공유되면** 포함되지만, 브라우저·OS가 제공하지 않는 오디오를 이 프로그램이 우회해서 수집하지는 않는다.

검사: 모니터 공유에 오디오 트랙이 반환된 경우 보존되는 단위 검사를 추가했다. Edge 157의 실제 브라우저 탭 공유에서 소리 포함 WebM 녹화·에셋 추가·타임라인 재생·소리 포함 MP4 출력을 확인했다(`node scripts/record-browser-test.mjs`). 합성 테스트 탭을 사용했으며, 실제 데스크톱 전체의 시스템 오디오 공유는 미검증이다.

근거: [MDN getDisplayMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getDisplayMedia), [Chrome 화면 공유 제어](https://developer.chrome.com/docs/web-platform/screen-sharing-controls).
