# 파이널 업그레이드 V4 · UI 사용성 보완

자막 빠른 입력칸을 한 줄 높이로 줄였다. PC는 28px, 모바일·태블릿은 32px이며 기존 줄바꿈 내용은 보존하고 입력칸 안에서 스크롤한다. 입력 영역 전체도 PC 54px, 작은 화면 60px로 줄여 속성 조절 공간을 확보했다.

## 검증 중 발견한 문제와 수정

- 모바일·태블릿의 공통 입력 스타일이 프로젝트 이름칸의 작은 크기를 덮어써 상단바가 45px까지 커지고 있었다. 해당 입력 스타일의 우선순위를 바로잡아 이름칸 30px, 상단바 38px로 맞췄다.
- 모바일 상단바의 로고·프로젝트 이름에 비율로 할당하던 공간을 내용 크기 기준으로 변경했다. 이름칸을 로고에서 2px 간격으로 붙이고 너비를 48~68px로 제한해 오른쪽 메뉴가 남는 공간을 활용하며 더 왼쪽에서 시작하도록 했다. PC·태블릿 배치는 유지한다.
- 작은 화면의 타임라인 하단은 28px인데 슬라이더는 34px여서 영역을 넘치고 있었다. 하단 영역을 40px로 조정하고 축소되지 않게 해 슬라이더가 잘리지 않도록 했다.
- 빠른 자막 입력의 제목·여백 때문에 한 줄 입력칸만 있어도 바깥 스크롤이 생겼다. 제목 줄 높이와 여백을 조정해 불필요한 스크롤을 없앴다.
- 자막 내용이나 스타일을 수정할 때 기존 자막을 삭제한 뒤 배열 끝에 추가하고 있어 목록 순서가 달라졌다. 기존 위치에서 갱신하도록 편집 명령을 직접 수정하고, 순서·다른 자막 보존·undo 회귀 검사를 추가했다.

## 실제 브라우저 확인

Windows의 headless Microsoft Edge에서 실제 편집기를 실행하고 모바일·태블릿 터치 환경을 에뮬레이션했다. PC 1440×1000, 모바일 320×740·390×844, 태블릿 768×1024·1024×768, 가로 화면 740×360을 확인했다.

합성 영상·오디오와 자막 40개를 넣어 화면 넘침, 한 줄 상단바, 자막 입력·줄바꿈 보존, 목록 순서, 미리보기 재생/정지, 터치 영상 드래그, 목록 터치 스크롤, 속성 변경, 도움말·Auto Cut·Auto Caption 모달 열기/취소를 확인했다. 페이지 전체 가로 넘침과 JavaScript 오류는 없었다. 모바일 저장 데이터는 Edge의 다운로드 화면 전환 영향을 피하도록 브라우저에서 생성된 JSON Blob을 캡처해 검사했다.

검증 스크립트는 `scripts/final-v4-ui-test.mjs`, 화면 캡처·측정 결과는 Git 제외 경로 `test-results/final-v4/`에 남긴다. 실제 휴대기기·가상 키보드·iOS Safari 및 음성 감지 정확도·전체 출력 품질을 검증한 결과는 아니다.

`npm test`의 72개 단위 검사와 `npm run build`가 통과했다. UI 검사는 개발 서버를 `npm run dev -- --port 5193 --strictPort`로 실행한 뒤 `node scripts/final-v4-ui-test.mjs`로 재현할 수 있다.

모바일 상단바 추가 조정 후 Edge에서 320·390·600·768·1440px 너비를 다시 확인했다. 한 줄 높이 38px와 가로 넘침 없음을 유지했고, 390px 화면의 메뉴 시작 위치는 약 166px에서 139px로 당겨졌다.
