# 최종 편의 기능 업그레이드 v1

- [v] F101. 스페이스바는 기본적으로 미리보기 재생/멈춤에 사용한다. 재생 위치/확대 등 range 슬라이더와 일반 버튼에 포커스가 있어도 재생/멈춤하며 버튼 활성화/페이지 스크롤로 전파하지 않는다. 문자·숫자 입력, 자막 편집, select·checkbox·radio, 모달·잠금·IME 입력은 기존 입력 동작을 보호한다. 반복 입력은 재생을 연속 토글하지 않는다.
- [v] F102. 열기·저장·앱 설치 옆에 같은 UI의 `새로 만들기` 버튼을 추가한다. 클릭하면 프로젝트 저장, 저장 없이 새 프로젝트, 취소를 선택하는 모달을 연다. 저장은 기존 JSON 다운로드를 사용하며 다운로드 요청만으로 프로젝트를 지우지 않고 사용자가 저장을 확인한 후 새 프로젝트 만들기를 선택하게 한다. 취소/저장 실패에는 기존 프로젝트를 유지한다.
- [v] F103. 새 프로젝트는 기존 빈 프로젝트 기본값으로 만들고 선택·재생 위치·클립보드·undo/redo·진행 중 편집 초안을 초기화한다. 기존 원본 파일 자체는 변경하지 않는다. 모달 중 편집/단축키를 잠그고 프로젝트 상태가 달라졌으면 작업을 거부한다.
- [v] F104. 에셋 카드의 ＋ 옆에 접근성 이름/툴팁이 있는 × 삭제 버튼을 추가한다. 타임라인에서 사용하지 않은 에셋은 즉시 목록에서 삭제한다. 사용 중이면 삭제될 영상 블록 수와 타임라인에서도 제거된다는 확인/취소 모달을 제공한다. 원본 누락 에셋도 삭제할 수 있다.
- [v] F105. 에셋 삭제는 해당 원본을 참조하는 영상 블록(합친 블록은 내부 참조가 있으면 블록 전체)을 함께 제거한다. 다른 블록의 시간·자막·라인은 유지하고 한 번의 undo로 복구한다. undo 이력에서 필요한 원본 참조는 기존 registry 보존 정책을 따르고 디스크 원본은 삭제하지 않는다.
- [v] F106. 도움말·문서 색인에 새 동작을 반영하고 기존 기능의 코드 부분을 직접 수정한다. 사용자 요청에 따라 브라우저/Edge 실행·타입 검사·빌드·테스트 등 검증 명령은 실행하지 않는다. 구현한 요구사항만 체크하며 실제 동작 검증은 미실행으로 명시한다.

구현 완료 기준으로 체크했다. 타입 검사·빌드·테스트·브라우저 실제 동작 검증은 사용자 요청에 따라 실행하지 않았다.
