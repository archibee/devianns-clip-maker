# 파이널 업그레이드 V3

## 요구사항과 완료 상태

- [v] Auto Cut·Auto Caption의 음성 인식 프리셋을 극단값 0/1 대신 실용적인 5단계 등간격 범위로 변경한다. 시작 임계값은 매우 높음부터 `0.3 / 0.4 / 0.5 / 0.6 / 0.7`, 종료 임계값은 `0.15 / 0.25 / 0.35 / 0.45 / 0.55`로 한다.
- [v] 시작과 종료 임계값에 0.15 간격을 두어 경계 확률에서 음성이 지나치게 끊기지 않도록 한다. 기존 편집 여백과 짧은 음성 보존 설정은 유지한다. 숫자를 직접 입력하는 고급 설정의 허용 범위는 변경하지 않는다.
- [v] 두 모달의 기존 0/1 극단 프리셋 설명을 새 설정에 맞게 수정한다. 이 문서가 이전 프리셋 수치 요구를 대체한다.
- [v] 자막 속성창을 위쪽 즉시 자막 입력 → 가운데 속성 조절 → 아래쪽 좁은 자막 목록 순으로 재구성한다. 세 영역은 각각 스크롤할 수 있고 목록 개수가 속성 위치를 밀어내지 않도록 한다.
- [v] 가운데 속성의 중복 텍스트 입력칸은 제거하고 위쪽 즉시 입력으로 통일한다. 다중 선택에서는 기존 공통 스타일 편집을 유지하고 단일 자막 텍스트 입력만 숨긴다.
- [v] 타임라인의 클립 개수 및 재생 슬라이더 옆의 ‘재생 위치’ 표시 문구를 PC·태블릿·모바일 모두 제거한다. 슬라이더의 접근성 이름은 유지한다.
- [v] 태블릿·모바일 상단바는 한 줄 그리드로 재구성한다. 프로젝트 이름 너비와 브랜드·메뉴 간격을 제한하고 폭에 따라 버튼 글자·여백을 조정한다. 공간이 부족한 메뉴는 가로 스크롤로 접근하며 다음 줄로 밀지 않는다.
- [v] 작은 화면의 미리보기 도구·재생 컨트롤·타임라인 도구도 줄바꿈을 막고 유연한 크기·필요 시 도구 가로 스크롤을 적용한다. PC 상단바 디자인은 유지한다.
- [v] 태블릿·모바일에서도 자막의 입력·속성·목록 세 영역을 독립적으로 유지하고 아래 목록 높이를 제한한다.

## 기준과 확인

음성 시작 기본값 0.5와 종료값을 0.15 낮추는 방식은 [Silero 공식 구현](https://github.com/snakers4/silero-vad/blob/master/src/silero_vad/utils_vad.py)을 참고했다. 0.3~0.7의 다섯 단계는 이 프로젝트의 사용 편의를 위한 설정이며 모든 영상에서 음성을 빠짐없이 잡거나 잡음을 제거한다는 보장은 아니다.

이번 변경은 일반 버전 저장소 `~/Desktop/CLIP_MAKER/devianns-clip-maker`의 편집·음성 감지·반응형 UI에 한정한다. Plus 저장소의 잘못된 경로에 적용했던 이번 V3 변경은 되돌렸으며 AI 기능을 이 저장소로 옮기지 않는다.

확인: 올바른 일반 버전 저장소에서 `npm run typecheck`와 `npx --no-install vitest run tests/auto-cut-presets.test.ts`의 4개 검사가 통과했다. 브라우저·실제 영상·실기기 UI 검증은 수행하지 않았다.
