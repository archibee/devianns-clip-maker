# 메타데이터·SEO 업그레이드 v3

- [v] SEO301. 일반 설치 PNG 아이콘의 둥근 모서리 바깥에 흰색이 저장된 문제를 수정한다. SVG 원본의 배경을 정사각형 전체에 채우고 일반/Apple touch/maskable PNG를 다시 생성한다. D/재생 도형과 색상은 유지하고 OS의 자체 아이콘 마스킹은 그대로 따른다.
- [v] SEO302. 일반 설치 아이콘(192/512)·maskable 아이콘(512)·Apple touch 아이콘(180)의 새 파일명을 manifest/HTML에 반영해 새 이미지 URL로 갱신한다. 앱 이름·시작 URL·scope·앱 식별 방식과 편집 기능은 유지한다. 기존 설치 앱의 OS 아이콘 캐시가 즉시 갱신된다고 보장하지 않는다.
- [v] SEO303. 루트의 `_v숫자.md` 문서를 `docs/checklists`, `docs/side-modules`, `docs/timeline`, `docs/media`, `docs/metadata`, `docs/pwa`로 나눈다. 각 문서의 버전명과 요구사항/완료 상태는 유지하고 이동 때문에 달라지는 상대 링크만 보정한다.
- [v] SEO304. `docs/README.md`에 기능별 문서 목록을 제공하고 루트 README에서 연결한다. 기존 README/구현 기록에서 이동한 문서 링크도 보정한다. 루트의 기본 진입/작업 문서와 고정 `CHECKLIST.md`, `CHECKLIST.sha256`은 유지하며 원문 해시를 변경하지 않는다.
- [v] SEO305. 타입 검사·빌드·고정 체크리스트 검사·이동 문서 링크를 확인한다. 정적 하위 경로에서 manifest/아이콘 크기·모서리 픽셀·브라우저 설치 요건을 간단히 확인하고 완료 체크한다. 실제 OS 재설치는 실행하지 않았다면 미실행으로 남긴다.

기존 설치 앱은 브라우저/OS의 아이콘 갱신 시점에 따라 이전 이미지를 계속 표시할 수 있다. 새 빌드를 배포한 뒤에도 이전 아이콘이면 기존 앱을 제거하고 다시 설치해 확인한다. 사이트 데이터 삭제는 요구하지 않는다.

확인: `npm run build`(타입 검사·고정 체크리스트 검사 포함) 통과. 버전 문서 20개를 이동하고 새 v3 문서를 추가했다. 저장소 Markdown 30개에서 로컬 링크 58개를 확인해 끊어진 링크가 없었다. Windows Edge의 정적 하위 경로에서 앱 부팅·4종 아이콘 크기/응답과 네 모서리 RGBA `[32,32,32,255]`를 확인했고 설치 요건 검사 오류도 없었다. 실제 OS 재설치/OS 아이콘 캐시 갱신 검사는 미실행이다.
