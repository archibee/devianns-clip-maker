# Devianns Clip Maker Plus · AI V2

## 목표와 UI

- AUTO CUT·AUTO CAPTION 옆에 AI 아이콘(반짝임 등)과 **AI** 버튼을 추가한다.
- 별도 모달에서 음성 분석 → 실제 자막 텍스트 생성 → 결과 확인·수정 → 완료 또는 취소를 처리한다.
- 기본 대상은 현재 선택한 라인으로 한다. 띄엄띄엄 있는 영상·원본 in/out·합쳐진 블록을 해석하고, 생성 자막은 원래 시간에 맞춰 새 라인에 배치한다.
- Auto Cut·Auto Caption과 독립된 모듈로 구현한다. 음성 추출·구간 감지 같은 저수준 기능만 재사용하며 다른 기능의 설정·상태·결과는 변경하지 않는다.

## 조사 결과와 가능성

2026-11-15 확인 기준, DeepSeek 공식 문서는 음성인식용 `POST https://api.deepseek.com/v1/tools/asr`를 제공하며 한국어도 지원한다. 따라서 DeepSeek를 통한 음성 전사는 문서상 구현 가능하다. V1에서 미확인으로 남긴 직접 음성인식 지원은 이 조사 결과로 갱신한다. [공식 가이드](https://api-docs.deepseek.com/guides/asr/)

입력은 multipart의 `file`이며 16-bit PCM WAV 또는 Ogg Opus를 받는다. 요청당 최대 8MiB·120초이며 스트리밍 전사는 지원하지 않는다. 스테레오는 왼쪽 채널만 인식하므로 앱에서 모노 음성으로 준비한다. [입력 규격](https://api-docs.deepseek.com/guides/asr/)

응답은 `request_id`, `text`, `duration_ms`로 구성되고, 단어·문장별 타임스탬프는 문서에 없다. 전체 영상을 한 번 전사한 문자열만으로 정확한 자막 시간을 얻는 방식은 피한다. [API 응답 계약](https://api-docs.deepseek.com/api/asr/)

## 권장 구조

`AI 모달 → 독립 로컬 음성 구간 분석 → 구간별 모노 WAV 추출 → 자체 백엔드 → DeepSeek ASR → 시간+텍스트 임시 결과 → 사용자 완료 → 새 자막 라인 일괄 적용`

- 로컬 VAD로 짧은 발화 구간을 찾고 구간별로 전사한다. 긴 발화는 요청 한도와 자막 가독성에 맞게 추가 분할한다. 각 요청에 구간 ID와 정수 마이크로초 프로젝트 시작·종료 시간을 연결한다.
- 음성이 없는 공간은 전송하지 않는다. 구간별 전사 텍스트는 해당 구간의 시간에 배치한다. 이 방식의 시간 정밀도는 발화 구간 단위이며 단어 단위 정렬을 보장하지 않는다.
- ASR 결과 자체로 자막을 만들 수 있다. 별도 DeepSeek 텍스트 모델의 문장 정리는 선택적 후속 단계이며, 시간·구간 ID를 임의로 재작성하게 하지 않는다.
- `modules/ai-caption`에 프런트 모달·작업 상태·자막 생성 계획을, 백엔드에는 공급자 어댑터와 표준 HTTP 처리 함수를 둔다. Vercel과 일반 서버의 진입점은 얇은 어댑터로 분리한다. 특정 플랫폼 SDK에 핵심 로직을 종속시키지 않는다.
- 구간별 업로드와 제한된 동시 요청으로 메모리·요청 크기를 관리한다. 실제 서버리스 한도는 DeepSeek 한도와 별개로 더 작을 수 있으므로 배포 설정에 맞춰 분할한다.

## 적용·실패 격리

- 모달을 여는 순간 프로젝트와 대상 라인을 스냅샷으로 고정한다. 기존 편집을 잠그되 분석 중 프로젝트 자체는 변경하지 않는다.
- API 실패·취소·응답 지연·부분 성공·모듈 로딩 오류를 모달 내부에서 처리한다. 실패한 구간은 재시도할 수 있고, 요청한 전체 작업이 성공하기 전에는 완료를 비활성화한다. 빈 전사는 정상 결과로 구분한다.
- 완료 시 프로젝트 변경 여부·텍스트·시간 범위·라인 수를 검증하고 새 라인의 자막을 한 번에 적용한다. 실패하면 부분 적용하지 않는다. 기존 영상과 자막은 보존하며 적용은 실행 취소 한 번으로 복구한다.
- 취소·닫기·페이지 종료는 미적용 결과를 폐기한다. 취소된 작업의 늦은 응답은 작업 ID/generation으로 무효화하고 Worker·버퍼를 해제한다. 공급자에 이미 도착한 요청은 취소해도 요금이 발생할 수 있다.
- 프런트 오류 경계와 API 타임아웃을 둬 AI 실패가 기존 편집기 전체의 오류로 번지지 않도록 한다. 독립성은 설계 목표이며 실제 구현 후 오류 경로 검증이 필요하다.

## 키와 외부 전송

- `.env.local`의 키는 백엔드에서만 읽는다. `VITE_` 접두어로 공개하지 않으며 브라우저 번들·응답·로그에 포함하지 않는다. 배포 환경에서는 플랫폼의 서버 환경변수로 별도 등록한다.
- 현재 `.gitignore`의 `*.local` 규칙이 로컬 환경 파일을 제외한다. 이번 조사에서는 키 내용을 읽거나 실제 API 요청을 보내지 않았다.
- AI 실행 전에 외부 음성 전송과 과금 가능성을 안내한다. 공개 배포에서는 인증·요청량 제한·입력 크기 제한을 두어 서버 키의 무단 사용을 막는다. 원본·전사·키를 자동 로그로 남기지 않는다.

이번 작업은 조사와 설계 문서 작성만 수행한다. 버튼·백엔드·모달은 아직 구현하지 않았으며 계정별 ASR 사용 가능 여부·실제 응답·품질은 미검증이다.
