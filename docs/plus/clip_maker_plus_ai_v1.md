# Devianns Clip Maker Plus · AI V1 개요

현재 브랜치에서 기존 편집기를 기반으로 Plus 버전을 개발한다. 이번 문서는 방향 정리이며 기능 구현이나 타이틀 변경은 아직 수행하지 않는다.

- 제품명, 화면 타이틀, 로고 텍스트는 **Devianns Clip Maker Plus**로 통일한다.
- AI 음성인식 API를 연결하여 음성 내용을 실제 자막 텍스트로 생성하는 기능을 추가한다. 기존의 음성 구간별 빈 자막 생성 기능과 구분한다.
- 사용할 AI는 **DeepSeek**를 예정한다. DeepSeek가 음성 파일과 시간 정보를 직접 처리할 수 있는지는 구현 전에 확인한다. 직접 음성인식이 지원되지 않으면 별도 STT 엔진으로 시간별 전사 결과를 얻고 DeepSeek를 자막 문장 정리 등에 연결하는 구조를 검토한다. 현재 단계에서 DeepSeek 단독 음성인식 가능 여부를 확정하지 않는다.
- 정적 파일만으로 실행하는 배포 제약을 해제하고 프런트엔드와 백엔드를 함께 운영한다. 기존 편집 기능은 유지하면서 AI 요청을 백엔드로 연결한다.
- 백엔드 핵심 로직은 특정 호스팅 플랫폼과 분리하고 표준 HTTP API로 제공한다. AI 공급자 호출도 어댑터로 분리한다.
- Vercel 배포가 가능해야 하지만 Vercel 전용 SDK·런타임·스토리지에 핵심 기능을 종속시키지 않는다. 일반 서버에서는 HTTP 서버로, 서버리스에서는 얇은 진입 어댑터로 같은 핵심 로직을 실행할 수 있도록 한다.
- API 키는 브라우저 번들에 포함하지 않고 백엔드 환경변수로 관리한다. 사용자가 AI 기능을 실행할 때 필요한 음성 데이터만 외부 API로 전송하며, 전송 여부를 안내한다.
- 서버리스의 요청 크기·실행 시간 제한은 플랫폼별 설정과 작업 분할로 대응할 수 있도록 설계한다. 긴 작업의 저장소·작업 상태 관리 방식은 후속 설계에서 결정한다.

기본 연결 흐름: **영상의 음성 추출 → 백엔드 음성인식 요청 → 시간 정보가 있는 전사 결과 → 필요 시 DeepSeek 처리 → 사용자 확인 → 타임라인 자막 적용**.

프런트엔드와 이식 가능한 백엔드로 전환하는 방향에는 구조적인 장애가 없다. 실제 음성인식 공급자/API 지원과 비용·데이터 처리 조건은 구현 전 확인이 필요하다. 기존 정적 전용·외부 전송 금지 지침은 Plus의 명시적 AI 요청 범위에서 변경되는 요구사항이며, 상세 설계 단계에 관련 작업 지침도 정합성을 맞춘다.
