# 모듈 업그레이드 V1

- [v] Auto Cut과 Auto Caption의 음성 인식 강도를 확률 범위 전체(0~1)에 대응하는 5단계 선형 프리셋으로 변경한다.
- [v] 매우 높음은 최대 감도(임계값 0), 매우 낮음은 최소 감도(임계값 1), 중간은 0.5, 높음·낮음은 각각 0.25·0.75로 설정한다. 시작·종료 임계값 모두 동일한 등간격 값을 사용한다.
- [v] 입력 범위와 검증을 0~1로 맞추고 종료 임계값이 시작 임계값과 같을 수 있도록 한다. 종료 임계값이 더 큰 설정은 차단한다.
- [v] 극단값 동작을 두 모달에서 안내한다. 최대 감도는 무음까지 음성 구간으로 포함할 수 있으며 최소 감도는 음성을 전혀 감지하지 못할 수 있다. 이는 정확도나 모델 자체의 성능 최대·최소를 의미하지 않는다.
- [v] 음성 판정 프리셋만 변경하고 Auto Cut 편집 여백 프리셋 및 두 기능의 독립 적용 방식을 유지한다.

| 강도 | 시작/종료 임계값 |
| --- | --- |
| 매우 높음 | 0 |
| 높음 | 0.25 |
| 중간 | 0.5 |
| 낮음 | 0.75 |
| 매우 낮음 | 1 |

높은 감도에는 낮은 임계값을 사용한다. 기존 버전 문서의 임계값 표기는 이 문서로 대체한다. 완료 표시는 코드 반영 기준이며 사용자 요청에 따라 실제 실행·브라우저 검증은 생략한다.
